# Printer Support

This document contains the approved SJK procedures for adding and troubleshooting school printers.

## Important Meaning of “Connect”

Users may use the word **connect** in two different ways:

1. The printer is not added to their device, and they want to add it.
2. The printer is already added, but they cannot print from it.

Do not assume what the user means by “connect.”

If the request is unclear, ask:

> Are you trying to add the printer to your device, or is the printer already added and you cannot print? Also, which printer are you trying to use?

Wait for the user to answer before providing instructions.

## Printer Identification

Ask which printer the user is trying to use if they have not already identified it.

The following names refer to the same printer:

* Learning Commons printer
* Library printer
* Learning Commons Kyocera
* Library Kyocera

The Learning Commons printer is a Kyocera TASKalfa MZ4001ci.

Its approved printer IP address is:

`192.168.1.205`

Students may add and use only the Learning Commons printer.

If a student requests access to another school printer, tell them to visit the IT Helpdesk.

## Main Printer Decision

For every printer question, determine whether the user wants to:

* Add a printer to their device
* Troubleshoot a printer that is already added
* Confirm which Wi-Fi network is required for printing

If they want to add a printer, follow the **Adding a Printer** procedure.

If the printer is already added but they cannot print, follow the **Printer Connection or Printing Problem** procedure.

If they are asking which Wi-Fi network is required, follow the appropriate Wi-Fi requirement section.

# Adding a Printer

## First Question

If the user wants to add a printer, ask:

> Which printer would you like to add?

If they say:

* Learning Commons
* Library
* Learning Commons printer
* Library printer
* Learning Commons Kyocera
* Library Kyocera

Continue with the Learning Commons printer setup instructions.

If they name any other school printer, respond with:

> Please visit the IT Helpdesk. The IT team will add the correct staff printer to your device.

Do not provide self-installation instructions for printers other than the Learning Commons printer.

## Learning Commons Printer Device Question

Before providing setup instructions, ask:

> Are you using a Windows laptop or a Mac?

Wait for the user to identify their device.

# Add the Learning Commons Printer on a Mac

Use this procedure only for the Learning Commons printer on macOS.

Before beginning, tell the user:

> Make sure your Mac is connected to either SJK Wi-Fi or Student Wi-Fi.

Then provide these instructions:

1. Open **System Settings**.

2. Select **Printers & Scanners**.

3. Click **Add Printer, Scanner, or Fax**.

4. Open the **IP** section.

5. In the Address field, enter:

   `192.168.1.205`

6. Set the protocol to **Line Printer Daemon – LPD**.

7. Wait while the Mac finds the printer information.

8. Confirm that the printer is detected.

9. Change the printer name if desired.

10. Click **Add**.

11. Wait for the setup to complete.

12. Open a document and print a test page.

If the Mac requests administrator credentials, does not detect the printer, or cannot complete the installation, respond with:

> Please visit the IT Helpdesk so the IT team can complete the printer setup.

Do not provide administrator credentials.

# Add the Learning Commons Printer on Windows

Use this procedure only for the Learning Commons printer on Windows.

Before beginning, tell the user:

> Make sure your Windows laptop is connected to either SJK Wi-Fi or Student Wi-Fi.

Then provide these instructions:

1. Open **Settings**.

2. Select **Bluetooth & devices**.

3. Select **Printers & scanners**.

4. Click **Add device**.

5. Wait for Windows to search for printers.

6. If the Learning Commons printer does not appear, select **Add manually**.

7. Choose **Add a printer using an IP address or hostname**.

8. Click **Next**.

9. Set the device type to **TCP/IP Device**.

10. Enter the following address:

    `192.168.1.205`

11. Allow Windows to detect the printer.

12. Select the detected Kyocera printer.

13. Choose a printer name if prompted.

14. Complete the setup.

15. Open a document and print a test page.

If Windows requests administrator credentials, cannot find an approved driver, or cannot complete the setup, respond with:

> Please visit the IT Helpdesk so the IT team can complete the printer setup.

Do not ask the user to download an unapproved printer driver.

Do not provide administrator credentials.

# Learning Commons or Library Printer Wi-Fi Questions

The Learning Commons printer and Library printer refer to the same printer.

The Learning Commons or Library printer works while connected to either:

* SJK Wi-Fi
* Student Wi-Fi

Use this section when a user asks:

* Do I need to be connected to SJK Wi-Fi?
* Can I print using Student Wi-Fi?
* Does the Library printer work on Student Wi-Fi?
* Does the Learning Commons printer require SJK Wi-Fi?
* Which Wi-Fi network should I use for the Library printer?
* Can students print while connected to Student Wi-Fi?
* Do I need to switch from Student Wi-Fi to SJK Wi-Fi?
* Can I use the Learning Commons printer from Student Wi-Fi?

Respond with:

> No, you do not need to be connected specifically to SJK Wi-Fi. The Learning Commons or Library printer works while connected to either SJK Wi-Fi or Student Wi-Fi.

Do not tell the user that only SJK Wi-Fi works for the Learning Commons or Library printer.

The user does not need to switch from Student Wi-Fi to SJK Wi-Fi to use the Learning Commons or Library printer.

For any other school printer, the device must be connected to SJK Wi-Fi.

# Printer Connection or Printing Problem

Use this procedure when the printer is already added but the user reports:

* I cannot connect to the printer.
* I cannot print.
* My document is not printing.
* The printer is connected, but nothing prints.
* The print job is not going through.
* The printer says unavailable.
* I selected the printer, but it does not print.
* The printer is not responding.

If it is unclear whether the printer is already added, ask:

> Is the printer already added to your device, or are you trying to add it?

If the printer has not been identified, ask:

> Which printer are you trying to use?

## Learning Commons Printer Wi-Fi Requirement

For the Learning Commons or Library printer, the user may be connected to either:

* SJK Wi-Fi
* Student Wi-Fi

Respond with:

> Please confirm that your device is connected to either SJK Wi-Fi or Student Wi-Fi, and then try printing again.

Then ask the user to:

1. Confirm that the device is connected to SJK Wi-Fi or Student Wi-Fi.
2. Return to the document they want to print.
3. Open the print menu.
4. Confirm that the Learning Commons printer is selected.
5. Try printing again.

Student Wi-Fi is approved for printing to the Learning Commons or Library printer.

The user does not need to switch from Student Wi-Fi to SJK Wi-Fi.

## Other School Printer Wi-Fi Requirement

For any school printer other than the Learning Commons or Library printer, the device must be connected to SJK Wi-Fi.

Respond with:

> Please confirm that your device is connected to SJK Wi-Fi, and then try printing again.

Then ask the user to:

1. Confirm that the device is connected to SJK Wi-Fi.
2. Return to the document they want to print.
3. Open the print menu.
4. Confirm that the correct school printer is selected.
5. Try printing again.

Student Wi-Fi may not provide access to staff printers.

## Printer Is Not Visible in the Print Menu

If the user says the printer is not listed or does not appear in the print menu, determine which printer they need.

If they need the Learning Commons or Library printer:

1. Ask whether they use Windows or macOS.
2. Provide the appropriate approved setup instructions.

If they need any other school printer, respond with:

> Please visit the IT Helpdesk. The IT team will add the correct printer to your device.

## Printing Still Does Not Work

Only use this section after the user confirms that:

* The printer is already added.
* The device is connected to the correct Wi-Fi network.
* The correct printer is selected.
* They tried printing again.
* The issue remains unresolved.

Respond with:

> The printer is added and your device is connected to the correct Wi-Fi network, but the issue is still unresolved. Please visit or contact the IT Helpdesk for further assistance.

Do not use this as the first response to a printer question.

# Required Assistant Behaviour

The assistant must follow these rules:

* Do not assume what the word “connect” means.
* Ask whether the user wants to add the printer or troubleshoot an already-added printer.
* Ask which printer the user is trying to use.
* Ask whether the device is Windows or macOS before providing setup instructions.
* Students may add only the Learning Commons or Library printer.
* The Learning Commons or Library printer works from either SJK Wi-Fi or Student Wi-Fi.
* The user does not need to switch from Student Wi-Fi to SJK Wi-Fi for the Learning Commons or Library printer.
* Other school printers require SJK Wi-Fi.
* Staff printers must be added by the IT Helpdesk.
* Do not immediately escalate ordinary printing problems.
* Check the required Wi-Fi connection before escalating.
* Do not assume that troubleshooting has already been completed.
* Ask only the next necessary question instead of giving every procedure at once.

# Prohibited Actions

The assistant must not:

* Provide administrator usernames or passwords.
* Reveal internal credentials.
* Recommend unapproved printer drivers.
* Instruct students to add staff printers.
* Tell users to change advanced network settings.
* Tell users to remove managed printer profiles.
* Ask users to repair printer hardware.
* Claim that a printer is offline without verified information.
* Claim that a support ticket was created without confirmation.
* Tell users that the Learning Commons or Library printer requires only SJK Wi-Fi.

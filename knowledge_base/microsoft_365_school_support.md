# Microsoft Office and Microsoft Account Basic Support

This document covers safe, day-to-day support for Microsoft Word, Excel, PowerPoint, OneDrive, and personal Microsoft accounts.

SJK manages school Google Workspace accounts. SJK does not manage personal Microsoft accounts, Microsoft passwords, Microsoft recovery information, or Microsoft verification methods.

## Global Support Rules

* Never ask for a password, verification code, recovery code, backup code, or authenticator code.
* SJK IT cannot reset, recover, unlock, or access a personal Microsoft account.
* Users should use Microsoft's **Forgot password** and account-recovery process for Microsoft account access.
* If a Microsoft work or school account belongs to another organization, the user must contact that organization's administrator.
* SJK IT can assist with Word, Excel, PowerPoint, OneDrive application behaviour, school devices, printing, files, and basic troubleshooting.
* Do not claim that a Microsoft password, account, licence, permission, protection setting, or recovery method was changed.
* Do not advise users to create additional Microsoft accounts to bypass access problems.
* Do not advise users to bypass Microsoft security, Protected View, macro security, device management, content filtering, or sharing controls.
* Begin with low-risk steps such as confirming the account, saving work, refreshing, reopening the file, trying the web version, restarting the application, and restarting the device.
* Do not delete school records, empty the Recycle Bin, disconnect OneDrive, remove managed accounts, reset Office, or reinstall Microsoft 365 unless directed by IT.
* Protect student, parent, and staff privacy. Do not ask users to paste grades, student details, financial information, or private documents into chat.
* Use the minimum sharing permission required.
* Menus and buttons may differ between Windows, macOS, Microsoft 365 for the web, and mobile applications.
* Escalate after the approved safe steps fail instead of repeating the same troubleshooting loop.

## Topic: Cannot Sign In to a Microsoft Account

**Intent Keywords:** cannot sign in microsoft, microsoft login not working, office 365 login, word sign in, excel sign in, powerpoint sign in, onedrive login failed, microsoft password not working

**Direct Answer:**

Confirm that you are using the correct Microsoft account. SJK does not manage Microsoft accounts or Microsoft passwords.

**Troubleshooting Steps:**

1. Open a private or incognito browser window.
2. Open the Microsoft sign-in page.
3. Enter the email address connected to the Microsoft account.
4. Check that Caps Lock is off.
5. Confirm that the email address is spelled correctly.
6. If the password is rejected, select **Forgot password?**
7. Follow Microsoft's identity-verification and password-reset steps.
8. Try signing in again with the new password.

**Escalation:**

If the account is personal, use Microsoft's sign-in help or account-recovery process. If the account belongs to another organization, contact that organization's administrator.

SJK IT can assist with application or device problems, but it cannot access or reset the Microsoft account.

**Bot Instruction:** Never ask the user for their Microsoft password or verification code. Do not direct Microsoft password-reset requests to the SJK IT Helpdesk.

## Topic: Forgot or Need to Reset a Microsoft Account Password

**Intent Keywords:** forgot microsoft password, reset microsoft password, forgot office 365 password, onedrive password reset, word password reset, cannot remember microsoft password

**Direct Answer:**

SJK does not manage Microsoft account passwords. Use Microsoft's **Forgot password** option to reset the account.

**Approved Steps:**

1. Open the Microsoft sign-in page.
2. Enter the email address connected to the Microsoft account.
3. Select **Forgot password?**
4. Choose an available verification method.
5. Enter the verification code sent by Microsoft.
6. Create and confirm a new password.
7. Sign in again using the new password.

**If Verification Is Unavailable:**

If you no longer have access to the recovery email address, phone number, authenticator, or other verification method, use Microsoft's sign-in helper or account-recovery process.

**Escalation:**

SJK IT cannot reset or recover a personal Microsoft account.

If the account belongs to another business, school, or organization, contact that organization's administrator.

**Bot Instruction:** Never ask for the password, new password, recovery code, authenticator code, or verification code. Do not tell the user that SJK can reset the Microsoft account.

## Topic: Common Excel Formula Errors

**Intent Keywords:** excel formula error, div 0, value error, ref error, name error, spill error, hash marks excel

**Direct Answer:**

The error code usually identifies the type of formula or display problem.

**Common Errors:**

- `#######`: The column may be too narrow, or a date or time value may be invalid.
- `#NAME?`: Excel does not recognize text in the formula, often because a function or name is misspelled.
- `#VALUE!`: A formula received an unexpected value or argument type.
- `#DIV/0!`: The formula is dividing by zero or an empty cell.
- `#REF!`: A referenced cell or range was deleted or is invalid.
- `#SPILL!`: A dynamic-array formula cannot place all results because cells in the output range are blocked.

**Troubleshooting Steps:**

1. Select the error cell.
2. Review the formula bar.
3. Confirm function names, parentheses, commas, and references.
4. Check whether referenced cells were deleted.
5. Check whether numbers are stored as text.
6. For `#SPILL!`, clear only unintended content blocking the output range.
7. Use Error Checking or Evaluate Formula when available.

**Escalation:**

Contact the workbook owner if the formula belongs to an official gradebook, financial file, or report.

**Bot Instruction:** Do not delete data merely to remove an error without understanding the formula.

## Topic: Create, Open, and Save a PowerPoint Presentation

**Intent Keywords:** create powerpoint, open presentation, save powerpoint, new presentation, save as pptx

**Direct Answer:**

Use the File menu to create, open, save, or save a copy of a PowerPoint presentation.

**Approved Steps:**

1. Select **File → New**.
2. Choose a blank presentation or approved school template.
3. Select **File → Open** for an existing presentation.
4. Select **Save** to save changes.
5. Select **Save As** to create a copy or choose another approved location.
6. Use `.pptx` for a standard presentation without macros.
7. Confirm that the file is saved before closing.

**Escalation:**

Contact the IT Helpdesk if PowerPoint cannot open or save any presentation.

**Bot Instruction:** Do not overwrite the original while testing a conversion or repair.

## Topic: Make a PowerPoint Presentation Readable

**Intent Keywords:** powerpoint design guidelines, slide text too small, presentation readability, too much text slides, accessible slides

**Direct Answer:**

Slides should support the speaker with clear, concise, readable content.

**Approved Guidance:**

- Keep each slide focused on one main idea.
- Use short phrases instead of large paragraphs.
- Use a readable and consistent font family.
- Use text large enough to read from the back of the room.
- Keep headings, margins, backgrounds, and object positions consistent.
- Use strong colour contrast.
- Do not rely only on red and green to communicate meaning.
- Keep charts and tables simple enough to read.
- Use images only when they support the message.
- Keep important content away from the extreme slide edges.
- Run the Accessibility Checker.

**Escalation:**

Ask the teacher or owner when branding or assignment requirements differ.

**Bot Instruction:** Do not sacrifice readability for decorative style.

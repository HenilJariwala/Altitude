# Zoom Workplace and Meetings School Support

This document covers safe, day-to-day support for Zoom Workplace, Zoom Meetings, Zoom Webinars, Zoom Rooms, Team Chat, Whiteboard, Clips, Docs, Scheduler, and related collaboration features used in a school environment.

## Global Support Rules

- Use these procedures for approved school, staff, student, and guest Zoom use.
- Zoom menus and feature names may differ between Windows, macOS, Linux, Chromebook, web browsers, iOS, Android, and Zoom Rooms.
- The current desktop application is called **Zoom Workplace**. Older guides may call it the Zoom desktop client or Zoom Cloud Meetings.
- Never ask a user to share a password, passcode, verification code, recovery code, authenticator code, or host key.
- For a personal Zoom account that uses an email address and Zoom password, use Zoom's **Forgot Password** process.
- If the user selects **Sign in with Google**, the password is managed by Google. School Google Workspace password resets must follow the school's approved IT Helpdesk process.
- If the user selects **Sign in with SSO**, access is managed by the organization connected to that SSO domain. Contact the organization's Zoom administrator or IT Helpdesk.
- Do not claim that SJK can reset a personal Zoom password, change a Zoom licence, enable a paid feature, or unlock an externally managed account.
- Do not share meeting links, meeting IDs, passcodes, host keys, recordings, transcripts, attendance reports, or participant information publicly.
- Use at least one approved meeting-security option, such as a passcode, Waiting Room, or authenticated-user restriction.
- Do not record students, staff, parents, guests, screens, chat, captions, or audio unless the host has authorization and participants receive the required notice.
- Do not advise users to bypass Waiting Rooms, passcodes, authentication, school filtering, privacy permissions, device management, recording controls, or host restrictions.
- Do not enable an unknown plugin, marketplace app, macro, browser extension, remote-control session, or AI feature without school approval.
- Begin troubleshooting with low-risk steps: confirm the correct meeting and account, test audio and video, check permissions, update Zoom, restart the app, try the web app, and restart the device.
- Do not uninstall Zoom, reset the application, delete recordings, remove managed profiles, or change firewall settings unless directed by IT.
- Many features depend on account type, licence, host role, device, administrator settings, and the meeting configuration.
- Do not promise that a feature is available merely because it exists in Zoom.
- Protect student, parent, and staff privacy. Do not ask users to paste confidential chat, meeting transcripts, student names, grades, health details, or private recordings into chat.
- Escalate after approved steps fail rather than repeating the same troubleshooting loop.

## Topic: Zoom Basic Use

**Intent Keywords:** what is zoom, help me use zoom, zoom basics, zoom workplace, video meeting basics

**Direct Answer:**

Zoom is a collaboration platform for video meetings, audio meetings, screen sharing, chat, whiteboards, recordings, and other communication features.

**Approved Steps:**

1. Use the Zoom Workplace app, Zoom Web App, mobile app, or an approved Zoom Room.
2. Join a meeting using a link, meeting ID, calendar event, or approved room controller.
3. Use the meeting toolbar for audio, video, participants, chat, reactions, sharing, and leaving.
4. Hosts receive additional controls for security, participants, breakout rooms, polls, captions, and recordings.
5. Ask which Zoom task the user needs help with when the request is broad.

**Escalation:**

Contact the IT Helpdesk if Zoom is unavailable on a school-managed device or required school access is missing.

**Bot Instruction:** Do not assume a specific problem when the user only asks for general Zoom help.

## Topic: Zoom System and Device Requirements

**Intent Keywords:** zoom requirements, computer requirements zoom, device needed for zoom, zoom hardware, supported zoom device

**Direct Answer:**

Zoom requires a supported device, a stable internet connection, and audio hardware. A camera is optional unless video is required.

**Approved Steps:**

1. Use a supported Windows, macOS, Linux, Chromebook, iOS, Android, or Zoom Room device.
2. Confirm that the device has a working speaker and microphone.
3. Use a camera only when video is needed.
4. Use an updated supported browser for the Zoom Web App.
5. Use a wired network or strong Wi-Fi when possible.
6. Close unnecessary high-bandwidth applications before an important meeting.

**Escalation:**

Contact the IT Helpdesk when a managed school device does not meet the requirements for a required Zoom activity.

**Bot Instruction:** Do not quote old operating-system or browser versions from legacy guides as current requirements.

## Topic: Download and Install Zoom Workplace

**Intent Keywords:** download zoom, install zoom workplace, install zoom app, zoom desktop app, get zoom

**Direct Answer:**

Download Zoom Workplace only from the official Zoom Download Center or an approved school software portal.

**Approved Steps:**

1. Confirm whether the device is school-managed or personal.
2. On a school-managed device, use the approved software portal or contact IT when installation is restricted.
3. On an approved personal device, download the correct installer for the operating system.
4. Run the installer and follow the normal prompts.
5. Open Zoom Workplace and confirm that it launches.
6. Do not install third-party Zoom packages or modified installers.

**Escalation:**

Contact the IT Helpdesk if installation requires administrator permission on a school-managed device.

**Bot Instruction:** Do not provide administrator credentials or recommend an unofficial download source.

## Topic: Forgot a Zoom Password

**Intent Keywords:** forgot zoom password, reset zoom password, zoom password not working, cannot remember zoom password

**Direct Answer:**

Password recovery depends on how the Zoom account signs in.

**Approved Steps:**

1. For an email-and-Zoom-password account, use Zoom's **Forgot Password** process.
2. For **Sign in with Google**, recover or reset the Google account password.
3. For **Sign in with SSO**, contact the organization that manages the SSO account.
4. Use only the recovery email or verification method shown by the identity provider.
5. Never share a reset link or verification code.

**Escalation:**

Contact the relevant account provider or organization administrator. Contact SJK IT only for school-managed Google or SSO access.

**Bot Instruction:** Do not send every Zoom password request to the school IT Helpdesk without identifying the sign-in method.

## Topic: Wrong Zoom Account Opens

**Intent Keywords:** wrong zoom account, personal zoom opens, switch zoom account, wrong profile zoom, multiple zoom accounts

**Direct Answer:**

The browser or Zoom Workplace app may be signed in to a different account from the one invited to the meeting.

**Escalation:**

Contact the account owner or Zoom administrator if the correct account is missing or not provisioned.

**Bot Instruction:** Do not merge, delete, or unlink accounts without confirmation from the account owner or administrator.

## Topic: Zoom Meeting Passcode Does Not Work

**Intent Keywords:** zoom passcode incorrect, meeting password wrong, cannot enter zoom passcode, invalid zoom passcode

**Direct Answer:**

**Bot Instruction:** Do not guess, disclose, or bypass a meeting passcode.

## Topic: Personal Meeting ID versus Generated Meeting ID

**Intent Keywords:** personal meeting id zoom, pmi zoom, generated meeting id, personal room zoom

**Direct Answer:**

A Personal Meeting ID is a reusable personal room. A generated meeting ID is created for a specific meeting and is usually safer for classes and external guests.

**Approved Steps:**

1. Use a generated meeting ID for most scheduled school meetings.
2. Use the Personal Meeting ID only when the account owner understands the reuse and security implications.
3. Enable a passcode, Waiting Room, or authentication.
4. Do not post a Personal Meeting ID publicly.
5. Review Personal Meeting Room settings regularly.

**Escalation:**

Contact the Zoom administrator when Personal Meeting ID use is disabled or controlled by policy.

**Bot Instruction:** Do not recommend a Personal Meeting ID for sensitive or widely distributed meetings.
